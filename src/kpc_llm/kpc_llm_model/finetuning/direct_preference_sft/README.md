    1 指令文本
    2 一般指令输出样本
    3 对一般指令输出的更偏好样本
    4 对一般指令输出的厌恶版本。
    前 1 2 项是跟 SFT 一样。
    只是要在 preference 的Target反向梯度。
    在厌恶样本做为 Target要正梯度更新。

    数据集的特殊处理。
        1， 3,4的产生最好由高阶模型产生，效率高。也可以由人产生，效率较低。
    微调训练的梯度这块的特殊处理。
